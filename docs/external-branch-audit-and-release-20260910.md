## 补齐的未发布改动

核对发现原客户兼容 Worktree `aws-b-customer-compat-20260908` 中仍有三项与本任务相关的改动未进入外接远程分支：

- `code_identity.rs`：抽取静态身份编码参数，比较移除这些参数值后的完整源码，检查字符串和括号闭合。
- `structured_output.rs`：对于明确要求单一编码身份输出的完整回复，只有两段答案之间存在已识别的纠正说明，且后一段正确、其他代码或业务内容没有变化，才选取上游提供的后一段答案。拒绝冲突业务数据、截断源码和多余正文。
- `format-base64-retest-20260909.md`：补齐此前另一条凭证阶段的诊断与复测记录。历史记录不作为本轮新执行的真实调用结果。

这三项已按文件差异审查后集成；没有加入系统提示词，没有增加重试次数，保留外接版此前的入站签名校验移除。

主目录另有一项错误诊断测试及历史运行产物，属于其他工作；没有修改或纳入此次外接发布。凭证、配置及原始日志不进入提交。
